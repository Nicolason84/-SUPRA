## Concurrency

Maximum active mission branches: 3.

Each branch must have:
- isolated outputs;
- explicit objective;
- evidence boundary;
- value-at-stake;
- monetization path or learning value;
- stop condition;
- human gate when an external irreversible action is required.

No branch may silently consume another branch's authority or outputs.

## Branch A — CASH NOW

Horizon:
- very short term: 0–2 weeks.

Purpose:
- first or next real payment;
- exploit existing proof, relationship, buyer, need or transaction;
- shortest path from existing patrimony to cash.

Eligibility:
- real beneficiary/buyer identifiable;
- problem already evidenced;
- deliverable possible with existing capabilities;
- payment or commercial next step can be tested quickly.

Preferred forms:
- paid diagnostic;
- decision memo;
- evidence dossier;
- commercial/operational analysis;
- deal facilitation;
- bounded implementation;
- productized expert service.

Rule:
CASH > PERFECTION.
REAL > THEORY.
STABILITY > NEW FEATURES.

## Admission gate for every mission

A mission is not admitted merely because it is interesting.

Required:
- reality reconstructed enough for the decision;
- beneficiary/economic owner identified;
- problem/value hypothesis explicit;
- existing capability match checked first;
- monetization or strategic learning path explicit;
- human time bounded;
- legal/ethical/consent constraints known enough;
- proof plan;
- kill criterion.

If decisionReady=false:
NO BUSINESS DECISION.

## Kill / pause conditions

Pause or kill a mission when:
- no real beneficiary can be identified;
- value-at-stake cannot be evidenced;
- buyer/payment path is absent and no strategic proof is gained;
- the same uncertainty repeats without new evidence;
- human attention cost dominates expected value;
- required authority is absent;
- action would violate legal, consent, privacy or safety boundaries;
- a cheaper existing capability can do the job.
