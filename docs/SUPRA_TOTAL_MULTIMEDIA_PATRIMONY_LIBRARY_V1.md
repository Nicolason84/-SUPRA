## Mission

Build the total multimedia patrimony library for NOVA ERA / SUPRA / ojO.

This is not a decorative media folder.
It is the canonical patrimonial index that connects:

THEORY
→ APPLICATION
→ TECHNIQUE
→ MODULE
→ ENGINE
→ CAPABILITY

→ APP
→ COMMERCIAL DOCUMENT

The library must preserve ONE canonical truth while allowing many representations and media.

## Non-negotiable rules

- Recover before create.
- Index/link before copying bytes.
- Do not duplicate an authoritative source unless backup/export is required.
- Every library object has provenance.
- Every derived asset links back to its source.
- Every product links to its technical lineage.
- Every sold product links to commercial evidence.
- Every invoice is distinguished from quote, order, payment proof and revenue recognition.
- UNKNOWN remains UNKNOWN.
- No commercial status may be inferred from a document title alone.
- No destructive cleanup.
- No canonical promotion without authority and evidence.
- Sensitive/private documents remain access-controlled and must not be published by default.
- Existing Google Drive / GitHub / local iMac / app bundles remain sources, not automatically duplicated stores.
